# ☕ Task App - 北欧ナチュラルデザインのタスク管理アプリ

Spring BootとMySQLを活用して構築した、会員登録・ログイン機能付きのタスク管理（CRUD）アプリケーションです。

単なる機能実装にとどまらず、ユーザーが毎日使いたくなるような「北欧ナチュラル」なUIデザインと、実務レベルの堅牢なセキュリティ（Spring Security）を両立させることを目指して開発しました。

## 🌟 アピールポイント

### 1. 職業訓練で培ったWebクリエイターとしてのUI/UX設計
無骨になりがちなタスク管理画面ですが、Figmaを用いたプロトタイピングやHTML/CSS/JavaScriptの体系的な学習経験を活かし、インクの温もりを感じる『Caveat』フォントや丸みを帯びたコンポーネントを採用。オリジナルの「北欧ナチュラル」な世界観を表現しました。

### 2. インフラ・品質保証の視点を持ったセキュアな設計
前職でのサーバーヘルプデスクやテスターとしての経験から、「動けば良い」ではなく、セキュリティと品質を重視しています。
- **BCryptによる暗号化:** 万が一データベースが流出しても解読されないよう、ソルトとストレッチングを用いた強力なハッシュ化を実装。
- **環境変数の活用:** 本番環境のパスワードなど、機密情報（秘密の鍵）をソースコードに直接記述せず、環境変数から読み込むセキュアな設計（見えない金庫）を徹底しています。

### 3. フレームワーク（IoC）の理解
Spring Securityのデフォルト画面に頼るのではなく、オリジナルのログイン画面へ案内するルーティングや、データベース（MySQL）と連携した認証処理を実装。
「制御の反転（IoC）」というフレームワークならではの設計思想を理解し、パスワードの照合処理をセキュアに委譲しています。
